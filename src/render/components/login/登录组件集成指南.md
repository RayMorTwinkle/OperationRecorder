# 登录组件集成指南

## 组件概述

这是一个基于 Vue 3 + Naive UI 的浏览器插件登录系统，支持用户认证、设备指纹、自动校验、状态同步等功能。

### 核心文件

```
src/render/components/login/
├── auth.js           # 核心认证逻辑（API调用、存储管理、自动校验）
├── useAuth.js        # Vue Composable（获取登录状态）
├── AuthProvider.vue  # 登录守卫组件（全屏/嵌入模式）
└── LoginModal.vue    # 登录弹窗（表单、记住密码）
```

## 快速开始

### 1. 基础配置（必须）

在 `auth.js` 中配置你的 API 端点：

```javascript
// auth.js 第 5-14 行
export const LOGIN_ENABLED = true // 是否启用登录
const TOKEN_EXPIRE_DAYS = 7 // token 过期时间
const API_BASE = 'https://your-api-endpoint.com/verify' // 修改为你的 API
const COLLECTION_NAME = 'crx_apikey' // 数据集合名
const CHECK_MACHINE_CODE = true // 是否检查设备指纹
```

### 2. 页面集成（三种方式）

#### 方式一：全屏守卫模式（适用于 Popup/Options）

未登录时显示全屏登录提示，登录后才显示内容。

```vue
<script setup>
import AuthProvider from '../../components/login/AuthProvider.vue'
import MyContent from './MyContent.vue'
</script>

<template>
  <AuthProvider>
    <!-- 登录后才会显示这里的内容 -->
    <MyContent />
  </AuthProvider>
</template>
```

#### 方式二：嵌入模式（不阻塞页面）

页面正常显示，通过 slot props 获取登录状态。

```vue
<script setup>
import AuthProvider from '../../components/login/AuthProvider.vue'
</script>

<template>
  <AuthProvider :fullscreen="false">
    <template #default="{ user, loading, canOperate, logout }">
      <div v-if="loading">加载中...</div>
      <div v-else-if="!user">游客模式</div>
      <div v-else>
        <p>欢迎，{{ user.userName }}</p>
        <button @click="logout">退出登录</button>
      </div>
    </template>
  </AuthProvider>
</template>
```

#### 方式三：使用 Composable（灵活控制）

不使用 `AuthProvider`，直接在组件中使用 `useAuth`。

```vue
<script setup>
import { useAuth } from '../../components/login/useAuth.js'

const { user, loading, logout } = useAuth()

const handleProtectedAction = () => {
  if (!user.value) {
    alert('请先登录')
    return
  }
  // 执行需要登录的操作
  console.log('当前用户:', user.value.userName)
}
</script>

<template>
  <div v-if="loading">加载中...</div>
  <div v-else-if="user">
    <p>欢迎，{{ user.userName }}</p>
    <button @click="logout">退出登录</button>
  </div>
  <div v-else>
    <p>未登录</p>
  </div>
</template>
```

## API 说明

### `auth.js` 核心方法

| 方法                           | 说明                             | 返回值                  |
| ------------------------------ | -------------------------------- | ----------------------- |
| `getUser()`                    | 获取当前登录用户                 | `Promise<User \| null>` |
| `saveUser(userId, userSecret)` | 登录并保存用户信息               | `Promise<User>`         |
| `logout()`                     | 退出登录                         | `Promise<void>`         |
| `reverifyUser()`               | 重新验证用户状态（用于定时校验） | `Promise<boolean>`      |
| `onAuthChange(callback)`       | 监听登录状态变化                 | `Function`（清理函数）  |

### `useAuth()` 返回值

```javascript
const { user, loading, logout, refresh } = useAuth()
```

| 属性      | 类型                | 说明         |
| --------- | ------------------- | ------------ |
| `user`    | `Ref<User \| null>` | 当前用户信息 |
| `loading` | `Ref<boolean>`      | 是否正在加载 |
| `logout`  | `Function`          | 退出登录方法 |
| `refresh` | `Function`          | 刷新用户信息 |

### User 对象结构

```javascript
{
  userId: '123456',
  userSecret: '******',
  userName: '用户_123456',
  token: 'token_xxx',
  loginTime: 1698765432000,
  lastVerifyTime: 1698765432000,
  strategy: ''  // 自定义策略字段
}
```

## 高级功能

### 1. 自动校验（Background）

`auth.js` 会在 Background 环境自动初始化，每小时校验一次登录状态：

- 插件安装时自动启动定时器
- 定时器触发 `reverifyUser()` 校验
- 校验失败时自动登出

**无需手动配置**，已自动集成（见 `auth.js` 第 146-173 行）。

### 2. 设备指纹

使用插件 ID + 随机 UUID 生成唯一设备标识，防止多设备登录：

```javascript
const deviceId = await getDeviceId() // 自动生成并缓存
```

### 3. 记住密码

`LoginModal` 会自动保存用户输入的账号密码到 `chrome.storage.local`，下次打开自动填充。

### 4. 跨页面状态同步

登录状态保存在 `chrome.storage.sync`，所有页面（Popup/Options/Content Script）自动同步。

## 开关控制

### 完全禁用登录功能

在 `auth.js` 中设置：

```javascript
export const LOGIN_ENABLED = false
```

所有登录相关逻辑会自动跳过，组件会直接显示内容。

## 常见问题

### Q1: 如何修改 API 端点？

修改 `auth.js` 第 10 行的 `API_BASE`。

### Q2: 如何自定义登录弹窗样式？

编辑 `LoginModal.vue`，基于 Naive UI 组件自定义。

### Q3: 如何在 Content Script 中使用？

直接导入 `useAuth`：

```javascript
import { useAuth } from '../render/components/login/useAuth.js'
const { user } = useAuth()
```

### Q4: 如何禁用自动弹窗？

```vue
<AuthProvider :auto-show="false"></AuthProvider>
```

### Q5: Token 过期时间怎么改？

修改 `auth.js` 第 8 行的 `TOKEN_EXPIRE_DAYS`。

---

## 总结

- **最简使用**：页面根组件包一层 `<AuthProvider>`
- **灵活控制**：使用 `useAuth()` 自定义逻辑
- **自动同步**：登录状态跨所有页面实时同步
- **开关控制**：`LOGIN_ENABLED = false` 一键禁用
