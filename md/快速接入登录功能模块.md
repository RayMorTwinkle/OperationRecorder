### 📝 **完整使用示例**

假设你要在其他页面（如 `Popup.vue`）中使用：

```vue
<script setup>
import { LoginGuard } from '@/components/login'
import { useAuth } from '@/composables'

const { userInfo } = useAuth()
</script>

<template>
  <LoginGuard
    placeholder="请登录以使用此功能"
    @login-success="(user) => console.log('登录成功', user)"
  >
    <!-- 登录后显示的内容 -->
    <div>
      <h1>欢迎 {{ userInfo.userId }}</h1>
      <!-- 你的应用内容 -->
    </div>
  </LoginGuard>
</template>
```
